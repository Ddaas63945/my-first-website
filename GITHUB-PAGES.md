# Публикация Vite-сайта на GitHub Pages

В отличие от предыдущего статического сайта, NEXUS PARFUM требует сборки.

1. Выполните `npm ci` и `npm run build`.
2. Публикуйте содержимое `dist/` через GitHub Actions Pages либо отдельную ветку публикации. Исходный `index.html` напрямую публиковать нельзя: он использует TypeScript и Vite.
3. В настройках Pages выберите используемый workflow или ветку с готовой сборкой.
4. Дождитесь успешного развёртывания и проверьте загрузку JS, CSS, изображений и переходы по hash-маршрутам.

`base: './'` в vite.config.ts поддерживает размещение в подкаталоге `my-first-website/`. Сайт не требует секретов для демонстрационной работы. Настройка настоящего backend и платежей — отдельная задача.

В этой задаче публикация на GitHub Pages не выполняется. До коммерческой публикации подтвердите права на фотографии и подключите настоящие бизнес-процессы.
