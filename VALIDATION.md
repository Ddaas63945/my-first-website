# Проверка NEXUS PARFUM

Дата: 20 октября 2026 года. Среда: Node.js 24.19, npm 11.9, Chromium.

## Установка и сборка

- Чистая установка `npm ci --cache /tmp/nexus-npm-cache --no-audit --no-fund` прошла из package-lock.json.
- `npm test`: 1 файл, 4 теста, все пройдены, пропущенных нет.
- `npm run build`: строгая проверка TypeScript и production-сборка Vite прошли.
- `npm run dev -- --host 0.0.0.0`: dev-сервер запускается на порту 5173.

## Браузерные сценарии

Проверены отдельным сквозным сценарием через Chromium DevTools Protocol (не входят в `npm test`):

- 11 товаров; поиск Black Opium; категории и бренд YSL; сброс фильтров.
- Сортировка цен по возрастанию и названий по алфавиту.
- Избранное, выбор объёма 100 мл, добавление, закрытие карточки клавишей Escape.
- Две позиции с разными товарами, изменение количества и объёма, сохранение после перезагрузки.
- Неверный checkout показывает ошибки всех четырёх контактов и отсутствующего согласия; корректный сохраняет один демозаказ и очищает корзину.
- История демозаказов и два избранных товара в кабинете.
- Сохранение настройки уменьшения анимации.
- Мобильное меню, раскрытие фильтров, каталог и корзина на экране 390 × 844.
- Отсутствие горизонтального скролла на главной и в каталоге при ширинах 320, 390, 768 и 1920 px.
- С отключённым WebGL работает 2D-презентация, описание и добавление в корзину.
- При событии потери WebGL-контекста сцена переходит в 2D.
- В обычном режиме движения: пропуск интро, смена аромата, фокус камеры на Bleu de Chanel и возвращение. При проверке явно подтверждено наличие WebGL canvas и отсутствие 2D-подмены.
- Просмотрены скриншоты главной, каталога, пространственного описания и мобильной главной.
- В завершённых сценариях ошибок JavaScript и неудачных запросов ресурсов не обнаружено. Оба локальных PNG-атласа загружаются.
- Production-preview на порту 4173: все 11 файлов HTML/JS/CSS/изображений отдаются с HTTP 200 и совпадают с `dist/`. В браузере проверены 11 товаров, Good Girl 80 мл в корзине, настоящая WebGL-сцена и мобильное отображение. Ошибок JavaScript и загрузки ресурсов нет.

При проверке исправлена реакция на штатное освобождение WebGL-контекста при перезапуске сцены в React StrictMode. Обработчик теперь снимается при размонтировании.

## Границы проверки

- Флаконы представлены фотографиями на плоскостях в WebGL-пространстве, не объёмными моделями. Кругового вращения фотографий нет.
- Для пяти товаров фотографий нет; это явно отмечено. Для шести подготовлены изображения по материалам пользователя.
- Режим покупки, профиль, адрес и история — локальные демонстрационные функции. Сервер, авторизация, наличие, платежи и доставка не подключены.
- Права для коммерческого использования фотографий не подтверждены. Официальные сайты пяти брендов возвращают 403 через прокси среды.
- Не измерялось достижение 60 FPS на реальных мобильных устройствах; эмуляция размеров не заменяет проверку физических устройств.
- GitHub Pages и публикация облачной среды не выполнялись.
