# Фотографии оригинальной парфюмерии

Фотографии намеренно не подменены рисунками или изображениями других товаров.
На момент разработки официальные сайты и Wikimedia Commons недоступны из среды (HTTP 403).
Ссылка images.openai.com, предоставленная пользователем, также вернула HTTP 403; её содержимое и права не удалось проверить.

Для завершения визуальной части нужны разрешённые к использованию фотографии:

| Товар | Версия / объём | Рекомендуемый локальный файл |
| --- | --- | --- |
| Tom Ford Oud Wood | Eau de Parfum, 50 мл | oud-wood.webp |
| Dior Sauvage Elixir | Elixir, 60 мл | sauvage-elixir.webp |
| Maison Francis Kurkdjian Baccarat Rouge 540 | Eau de Parfum, 70 мл | baccarat-rouge-540.webp |
| Byredo Bal d’Afrique | Eau de Parfum, 50 мл | bal-dafrique.webp |
| Kilian Angels’ Share | Eau de Parfum, 50 мл | angels-share.webp |
| Yves Saint Laurent Libre | Eau de Parfum, 50 мл | libre.webp |

Используйте фото реального соответствующего флакона на прозрачном фоне, желательно от 1000 px по высоте. Зафиксируйте источник, автора, лицензию / разрешение правообладателя. Наличие фото в интернете само по себе не даёт разрешения на коммерческое использование.

После проверки сохраните файл здесь и замените `image:null` для соответствующего товара в `script.js` на `image:'./assets/имя-файла.webp'`. Относительный путь работает в подкаталоге GitHub Pages. Каталог и центральная презентация используют одно изображение; анимация приближения и обратный переход подключаются автоматически. На главной для фотографии уже предусмотрены парение, мягкая тень и отражение. Если фото не загрузится, посетитель увидит явное сообщение, а не сломанную картинку.
