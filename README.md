# NEXUS PARFUM

Пространственный демонстрационный бутик парфюмерии: React 19, TypeScript, Vite, Three.js, React Three Fiber, drei, GSAP, Tailwind CSS 4, Zustand и Lucide React.

## Запуск

Node.js 22.12+ (проверено на 24.19), npm и браузер с WebGL 2. Для запуска без WebGL предусмотрен 2D-режим.

```bash
npm ci
npm run dev -- --host 0.0.0.0
```

Рабочий каталог облачной среды: `/workspace/my-first-website`. Vite по умолчанию использует порт 5173. Установка зафиксирована в `package-lock.json`.

```bash
npm test
npm run build
npm run preview -- --host 0.0.0.0
```

`npm run build` выполняет строгую проверку TypeScript и создаёт `dist/`. Dev-сервер и preview не являются production-серверами.

## Что реализовано

- Настоящая WebGL-сцена: пространственные фотографии, частицы с формированием NEXUS, покачивание, реакция на курсор, GSAP-переходы камеры и расположения объектов при выборе аромата, стеклянная панель, короткое пропускаемое интро.
- Навигация по 11 ароматам кнопками, колесом и горизонтальным свайпом; каталог переключается в пространственный режим.
- Каталог с поиском, брендами, категориями, избранным, сортировкой по цене/названию и быстрым просмотром.
- Несколько объёмов, отдельные позиции по объёму, пересчёт цены, смена объёма, количество до 99, удаление и сохранение корзины.
- Демонстрационный checkout с валидацией имени, телефона, email и адреса, комментарием, согласием на локальное сохранение и историей демозаказов.
- Профиль, адрес, заказы, избранное, настройка уменьшения анимации и удаление данных в кабинете.
- Мобильная компоновка, ограничение DPR, остановка рендера вне экрана, prefers-reduced-motion, 2D-режим при отсутствии/потере WebGL, ленивые страницы и загрузка сцены.

## Изображения и 3D

В коллекции 11 реальных наименований. Для шести использованы обработанные фотографии, предоставленные пользователем: Dior Sauvage Elixir, Bleu de Chanel, Black Opium, Good Girl, My Way и Baccarat Rouge 540. Для пяти остальных — явно подписанные заглушки. См. `public/perfumes/README.md`.

Флаконы — пространственные фотографии (2.5D) внутри настоящей WebGL-сцены, а не объёмные модели. Отдельные GLB, круговое вращение и физически точные отражения стекла требуют дополнительных лицензированных ресурсов. Автоматическая обработка фона может изменить мелкие детали; перед коммерческой публикацией нужны оригинальные подготовленные файлы и проверенные права. Равные 60 FPS на всех устройствах не гарантируются.

## Демо и данные

Цены в рублях тестовые, не оферта. Нет наличия, платежей, отправки заказов, доставки, настоящей авторизации и серверного хранения. Профиль, адрес, корзина, избранное и до 50 демозаказов хранятся в localStorage под ключом `nexus-parfum-v1`. Вводите вымышленные сведения. Данные можно удалить в кабинете → Настройки.

## Структура и будущий backend

- `src/components/3d/Showroom.tsx`: WebGL-сцена и камера, изолированные от бизнес-логики.
- `src/components/ui/`: изображения, карточки, диалоги и корзина.
- `src/pages/`: главная, каталог, кабинет, checkout, информация о проекте.
- `src/data/products.ts`: типизированные товары, объёмы, тестовое ценообразование, UV-области атласов.
- `src/store/shop.ts`: типизированные CartItem, Profile, Order, операции корзины/заказов и локальный persistence через Zustand.
- `src/hooks/`: маршруты по hash и настройки движения.
- `src/utils/validation.ts`: валидация checkout.
- `src/styles/index.css`: Tailwind и стили интерфейса.

Для подключения Supabase следует добавить отдельный API-адаптер, заменить локальные операции профиля и заказов на запросы к backend, реализовать настоящую авторизацию и RLS, перенести авторитетный расчёт цен/наличия на сервер и отдельно настроить платежи. Не используйте локальный профиль как проверку личности. Секреты в клиентский код не добавлять.

## Проверки

`npm test`: четыре теста бизнес-логики — объединение объёмов, пересчёт и ограничения корзины, снимок демозаказа, валидация контактных данных. Дополнительно при разработке проверяются реальные пользовательские сценарии в Chromium на широком и мобильном экранах. Результаты приведены в `VALIDATION.md`.

Для GitHub Pages публикуется собранный каталог `dist/`, см. `GITHUB-PAGES.md`.
