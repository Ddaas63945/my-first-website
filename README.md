# MAISON NOIR

Одностраничная демонстрационная витрина парфюмерии на русском языке. Чистые HTML, CSS и JavaScript, без сборки, npm, сторонних библиотек и серверной части.

## Запуск

Откройте `index.html` в браузере. Для проверки HTTP: `python3 -m http.server 8000` из корня репозитория. Стили и скрипты подключены относительными путями.

## Возможности

Шесть ароматов, фильтр брендов, модальная презентация с анимацией, корзина с количеством и итогом в PLN, избранное, демонстрационный кабинет и локальная история демозаказов. Данные сохраняются в localStorage. Регистрации, реальных платежей и отправки заказов нет. Учтена настройка уменьшения движения.

## Важное ограничение фотографий

Подтверждённые фотографии оригинальных флаконов пока не получены: источники и предоставленная ссылка недоступны из среды разработки (HTTP 403). На сайте это явно обозначено. Никакие изображения товаров не выдуманы и не подменены. Инструкция подключения лицензированных локальных фотографий — в [assets/README.md](assets/README.md). Полный визуальный эффект парения и перелёта фотографии доступен после их добавления; сейчас работает анимированная презентация с заглушкой.

## GitHub Pages

Сохраните файлы `index.html`, `style.css`, `script.js`, `.nojekyll` и каталог `assets` в корне ветки `main`. В Settings → Pages выберите Deploy from a branch → main → / (root). Сборка и секреты не требуются. Не удаляйте `.nojekyll`.

Адрес после успешного развёртывания: https://ddaas63945.github.io/my-first-website/ . Публикацию проверяйте по выполнению GitHub Actions и содержимому страницы, а не только по наличию коммита.
