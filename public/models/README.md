# Модели
Лицензированные GLB/GLTF-модели не предоставлены. Текущая WebGL-сцена размещает фотографии флаконов на прозрачных плоскостях в 3D-пространстве (2.5D). Круговое вращение фотографий не имитируется. Будущие модели можно подключать отдельным компонентом сцены через useGLTF с отдельным указанием лицензии и обработкой ошибок.
