# Изображения NEXUS PARFUM

`collection.png`: Dior Sauvage Elixir, Bleu de Chanel Eau de Parfum, YSL Black Opium, Carolina Herrera Good Girl.
`collection-two.png`: Giorgio Armani My Way, Maison Francis Kurkdjian Baccarat Rouge 540 Eau de Parfum.

Источники — фотографии, присланные пользователем в этой задаче. PNG-атласы подготовлены с автоматическим удалением фона инструментом обработки изображений. Это обработанные фотографии, не GLB-модели; надписи и детали после автоматической обработки требуют проверки перед коммерческим использованием. Подтверждение коммерческой лицензии не предоставлено. Названия и товарные знаки принадлежат их правообладателям.

Для Tobacco Vanille, Aventus, Libre, Le Male Elixir и Layton изображения отсутствуют; интерфейс явно показывает «Фото ожидается». При попытке открыть официальные сайты Tom Ford Beauty, Creed, Jean Paul Gaultier, Parfums de Marly и YSL Beauty сетевой прокси среды вернул 403. Доступ и условия повторного использования не подтверждены, поэтому сторонние изображения не скачивались.

Разметка атласов и UV-областей находится в `src/data/products.ts` (`atlasCrop`). Чтобы добавить разрешённые фотографии, сохраните их локально и обновите визуальный источник/область для соответствующего товара. Не подменяйте отсутствующие фотографии выдуманными флаконами.
